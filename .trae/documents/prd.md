## 1. 产品概述

宠物医院在线挂号系统，面向宠物主人、医生和管理员三类角色，实现宠物档案管理、在线挂号排队、就诊记录闭环和运营数据统计的完整数字化诊疗流程。

- 解决宠物主人挂号排队不便、病历管理混乱的痛点，提升就诊效率和体验
- 目标用户：城市养宠家庭、宠物医院医生及运营管理人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 宠物主人 | 手机号注册 | 管理宠物档案、在线挂号、查看病历与提醒 |
| 医生 | 管理员创建账号 | 查看挂号列表、填写诊断处方、管理排班 |
| 管理员 | 系统预设账号 | 数据统计、医生排班管理、号源设置 |

### 2.2 功能模块

1. **登录注册页**：手机号注册/登录，角色选择（宠物主人）
2. **宠物档案页**：宠物列表、添加/编辑宠物信息
3. **挂号预约页**：选科室、选医生、选时段、提交挂号
4. **挂号单页**：排队号、预计等候时间、挂号详情
5. **医生工作台**：今日挂号列表、排队顺序、患者详情
6. **就诊记录页**：诊断结果、处方、医嘱填写与提交
7. **个人中心页**：病历时间线、疫苗到期提醒、复诊提醒
8. **管理员仪表盘**：挂号量统计、科室接诊数、医生工作量、热门科室排行
9. **排班管理页**：医生排班设置、号源数量配置

## 3. 核心流程

### 3.1 宠物主人挂号流程
宠物主人登录 → 添加/选择宠物 → 选择科室 → 选择医生 → 选择时段 → 提交挂号 → 生成挂号单（含排队号和预计等候时间）

### 3.2 医生就诊流程
医生登录 → 查看今日挂号列表 → 点击患者 → 查看宠物档案和历史病历 → 填写诊断结果、处方和医嘱 → 提交就诊记录

### 3.3 管理员管理流程
管理员登录 → 查看统计数据 → 管理医生排班 → 设置号源数量

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：温暖的珊瑚橙 (#FF6B6B) 搭配薄荷绿 (#4ECDC4)，传递关爱与生命力
- 辅助色：暖灰 (#2C3E50) 用于文字，浅米色 (#FFF8F0) 用于背景
- 按钮风格：圆角 (12px) 按钮，主按钮带轻微阴影和悬停动效
- 字体：标题使用 "Nunito" 圆润友好的字体，正文使用 "DM Sans" 清晰易读
- 布局风格：卡片式布局，顶部导航栏，左侧边栏（医生/管理员）
- 图标风格：线条圆润的线性图标，搭配宠物相关的插画元素
- 整体风格：温暖亲切、专业可信，融合宠物元素营造轻松氛围

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录注册页 | 表单区 | 居中卡片、宠物爪印装饰、渐变背景、输入框带图标 |
| 宠物档案页 | 宠物卡片 | 圆形头像、品种标签、渐变边框卡片、悬浮阴影 |
| 挂号预约页 | 步骤条 | 三步进度指示器、科室图标卡片、医生头像列表、时段网格 |
| 挂号单页 | 排队信息 | 大号排队号码、进度条、动态等待提示 |
| 医生工作台 | 挂号列表 | 列表项带状态标签、点击展开详情、侧边宠物档案面板 |
| 就诊记录页 | 表单区 | 分区表单（诊断/处方/医嘱）、药品动态添加行、提交确认弹窗 |
| 个人中心页 | 时间线 | 垂直时间线、提醒卡片带倒计时、宠物切换标签 |
| 管理员仪表盘 | 数据卡片 | 数据大卡片、柱状图/饼图、排行榜样式列表 |
| 排班管理页 | 日历网格 | 周视图日历、拖拽排班、号源数量输入框 |

### 4.3 响应式设计
- 桌面优先设计，适配 1280px+ 主流分辨率
- 平板端（768px-1024px）侧边栏折叠为顶部导航
- 移动端（<768px）单列布局，底部导航栏，卡片全宽展示
- 触屏优化：按钮最小 44px 触摸区域，时段选择网格适配手指操作

### 4.4 3D 场景指导
- 不适用（此项目为 2D Web 应用）
